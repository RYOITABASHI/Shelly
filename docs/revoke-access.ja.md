# Shelly が外部に開く経路をすべて止める・取り消す方法

[English](./revoke-access.md)

Shelly は、ChatGPT アプリ、ClosePaw、MCP クライアント、定期実行エージェントなど、他のものにスマホを操作させることができます。このページでは、それぞれの止め方、認証情報の取り消し方、本当に止まったかの確認方法をまとめます。

ここに書いたコマンドとメニュー名は、すべてコードで確認済みです。アプリ内にその手段がない場合は、ないと書いています。

`shelly ...` のコマンドは、Shelly のターミナルタブで実行します。

## 1. ChatGPT リモート操作（`shelly codex pair`）

内容: Shelly が公式の `codex remote-control --no-daemon` をスマホ上で動かします。ChatGPT アプリの Codex から、このスマホでコマンドを実行できます。ChatGPT のサインインが必要です。

### 止める

- `shelly codex pair` でタブ内に起動した場合: そのタブで Ctrl-C を押すか、タブを閉じます。
- `shelly codex pair --background` で起動した場合: `shelly codex stop` を実行します。
- 「Keep ChatGPT connected」をオンにしている場合: `shelly codex autostart off` を実行するか、設定 > Codex Login を開いて **Keep ChatGPT connected** をオフにします。コマンドは、動いているバックグラウンドのホストも止めます。オンの間は通知が表示され、その通知の Disconnect でも止められます。

「Keep ChatGPT connected」は、設定画面で確認ダイアログを通したときだけオンにできます。ターミナルからはオフにしかできません。ChatGPT 側が自分でオンにできないようにするための仕様です。

### 止まったか確認する

- `shelly codex status` で、バックグラウンドのホストが動いていないと表示されること。
- `shelly codex autostart status` が `off` と表示されること。これは Shelly が書く状態ファイルを読むだけなので、目安として見てください。実際のスイッチは設定 > Codex Login にあります。
- Shelly を閉じて開き直し、ホストが戻ってこないこと。

### 取り消す

1. **ChatGPT 側からこのスマホを削除する。** スマホ側のホストを止めても、ChatGPT 側の端末登録は消えません。Shelly のメッセージにも「完全に取り消すには、ChatGPT アプリでもこの端末を削除してください」という趣旨の案内があります。ChatGPT アプリ内の正確なメニュー名は、OpenAI 側のもので変わる可能性があるため、確認していません。
2. **信頼したプロジェクトを外す。** `shelly codex trust <dir>` は、`~/.codex/config.toml`（`CODEX_HOME` を設定している場合は `$CODEX_HOME/config.toml`）に、`trust_level = "trusted"` を持つ `[projects."<パス>"]` テーブルを書き込みます。`shelly codex untrust` のようなコマンドはありません。外すには、そのファイルを開いて該当テーブルを削除します。結果は `shelly codex status` で、信頼済みプロジェクトの一覧から確認できます。
3. **Codex からサインアウトする。** Codex の ChatGPT ログインは `~/.codex/auth.json`（権限 0600）に保存されます。このファイルを削除してください（`rm ~/.codex/auth.json`）。ChatGPT のサインインがないと、リモート操作は起動できません。このファイルの有無は `shelly-doctor` で確認できます。Shelly に Codex 用の「サインアウト」ボタンはありません。OpenAI 側のログインも終わらせたい場合は、ChatGPT アカウント自身のセキュリティ設定を使ってください。

## 2. ClosePaw への引き渡し（`shelly closepaw`）

内容: ターミナル（たとえば ChatGPT）からのタスクを ClosePaw アプリに渡し、ClosePaw がスマホ上の他のアプリを操作します。

### リクエストを拒否・取り消す

- Shelly 信頼版の ClosePaw では、リクエストごとにスマホ上での承認が必要です。承認は、通知の **Approve** をタップする（端末のロック解除が必要）か、Shelly のチャットで `approve <hash>` と返信します。ただの「OK」では承認されません。
- 拒否するには、チャットで `reject <hash>` と返信するか、通知から拒否するか、`shelly closepaw reject <requestId>` を実行します。ChatGPT 側から拒否はできますが、承認は決してできません。
- 何もしなければ、リクエストは期限切れになります。チャットの文面には 10 分で期限切れと表示されます。

### 無効にする

- ClosePaw アプリをアンインストールします（Android 設定 > アプリ）。エージェントからの引き渡しは「ClosePaw is not installed」で拒否されます。
- 信頼ショートカットだけをやめたい場合は、Shelly 信頼版を公式の ClosePaw に入れ替えます。公式版は毎回自分の確認画面を出し、Shelly のトークンも受け取りません。
- ClosePaw のステップを含むエージェント: そのようなエージェントを承認すると、エージェントを編集するまで、以後の実行でもそのステップが承認されたままになります。取り消すには、エージェントを編集または削除します（4章）。
- Shizuku は、ClosePaw が仮想ディスプレイに使う別アプリです。Shizuku アプリまたは Android 設定から停止・アンインストールします。その後、ClosePaw のバックグラウンド実行は失敗し、Shelly は「Start Shizuku」と表示します。
- ClosePaw のアクセシビリティサービス: Android 設定 > ユーザー補助 > ClosePaw で、オフにします。
- ClosePaw 自身の AI 認証情報は ClosePaw の中に保存されています。そのアプリ内で削除してください。

### 止まったか確認する

Android 設定 > アプリで ClosePaw が消えていること、ユーザー補助で ClosePaw のサービスがオフになっていることを確認します。確認のために `shelly closepaw "<goal>"` を実行するのはおすすめしません。実際のリクエストが作られ、それを拒否する手間が増えるためです。

## 3. MCP サーバー

内容: スマホ上のポート 8767 で動く HTTP サーバーです。同じ Wi-Fi や VPN 上の MCP クライアント（Claude Code など）がツールを呼び出せます。すべてのネットワークインターフェース（`0.0.0.0`）で待ち受け、リクエストごとに Bearer トークンを確認します。

### 止める

- 設定 > Agents > **MCP Server** をオフにします。オフの間はサーバーが停止します。初期値はオフです。
- 設定 > Agents > **MCP: Allow exec/write (dangerous)** をオフにします。初期値はオフです。オンにすると `run_command` と `write_file` が追加されます。呼び出しのたびにスマホ上の承認ポップアップが必要で、CRITICAL リスクのコマンドは拒否されます。

### トークン

- Bearer トークンは、最初に必要になったときに生成され、SecureStore に保存されます。同じ設定セクションの **Copy MCP Token** でコピーできます。
- **このトークンを再生成・リセットするボタンはありません。** 一度作られたトークンを置き換えたり削除したりするコードは見つかりませんでした。クライアントにトークンが渡っている場合、アプリ内での取り消し手段はサーバーをオフにすることだけです。保存されたトークンがなくなった場合（Shelly のアプリデータ消去や再インストールなど）にだけ、新しいトークンが作られると考えられますが、試していません。

### 止まったか確認する

トグルをオフにした状態で、同じネットワークの別の端末からポート 8767 に接続しても、拒否されること。

## 4. 定期実行・自律エージェントと、保存したキー

### エージェント

- 1 つを一時停止: サイドバーでそのエージェントを開き、**Pause** をタップします。スケジュールが止まります。**Resume** で戻せます。
- すべて停止: サイドバーの **STOP ALL** ボタンがグローバルのキルスイッチです。**RESUME** で戻せます。STOP-ALL の間は、「Keep ChatGPT connected」をオンにできません。
- 削除: サイドバーでエージェントを削除し、確認します。プランとスケジュールが消えます。
- 設定 > Agents > **Approve Agents from ChatGPT**: ChatGPT から `shelly agent confirm` でエージェントを承認させたくない場合はオフにします。Shelly 内での承認はそのまま使えます。

### キーとコネクタの認証情報

- AI プロバイダのキー: 設定 > API Keys。各行に **Clear** ボタンがあります。
- ソーシャルコネクタの認証情報（Bluesky、Discord など）: 設定 > Social Connectors でコネクタを削除します。SecureStore 内のシークレットと、エージェントの環境ファイル内の該当エントリが消えます。
- Codex のログイン: 1章を参照。
- ここでキーを消しても、消えるのは Shelly 内のコピーだけです。キーが漏れたと思う場合は、提供元でも失効させてください。

## 5. 止めても元に戻らないもの

- すでに ChatGPT、OpenAI、その他の AI プロバイダに送られたもの（プロンプト、コマンド出力、Codex が読んだファイルなど）は、先方に残ります。各サービスのアカウントで、その規約に従って削除してください。
- ClosePaw がすでに実行したスマホ操作は巻き戻りません。送ったメッセージや変更したリストはそのままです。
- コマンドがすでに書き込み・変更したファイルは、変更されたままです。
- トークンをすでにコピーした MCP クライアントは、そのトークンを知ったままです（3章）。
- Shelly にはテレメトリがないため、Shelly 側のサーバーに消すべきデータはありません。README のプライバシーの節も参照してください。
